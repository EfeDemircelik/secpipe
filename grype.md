# Grype

Grype is a vulnerability scanner for images and filesystems. It can scan image directly, or scan a pre-generated SBOM (e.g. from Syft).

## 1. Prerequisites

* Linux (x86_64) environment

* `curl`installed

    > $ sudo apt-get install curl

* `sudo` privilages

* Syft installed (needed for SBOM-based scan)

* jq package

    > $ sudo apt-get install jq

## 2. Installation

* Install Grype

> $ curl -sSfL https://get.anchore.io/grype | sudo sh -s -- -b /usr/local/bin

The installation script downloads the Grype and places the executable in `/usr/local/bin`.

## 3. Usage

### Scan a container image:

> $ grype `<image_name:tag>`

Grype analyzes the image and reports detected vulnerabilities. 

#### Example output:

| NAME | INSTALLED | TYPE | VULNERABILITY | SEVERITY | EPSS | RISK |
| --- | --- | --- | --- | --- | --- | --- |
| busybox | 1.37.0-r31 | apk | CVE-2025-60876 | Medium | 0.3% (20th) | 0.2

***EPSS***: Exploit Prediction Scoring System score, representing the probability that a vulnerability will be exploited in the wild.  
***RISK***: Calculated risk score combining vulnerability information such as severity and exploit likelihood.

### Update the vulnerability database:

> $ grype db update

Grype uses a vulnerability database to match installed packages againts known CVEs.   
Updating the database ensures that the latest vulnerability information is used.

### Scan an SBOM generated by Syft

First, generate an SBOM:

> $ syft scan `<image_name:tag>` -o cyclonedx-json > `<output_file_name>`

Then scan the SBOM with Grype:

> $ grype `<file_name>`

### Export results as JSON

> $ grype `<image_name:tag>` --output json | jq . > `<output_file_name>`

Outputs the scan result as JSON, uses `jq` to format it, and saves it to a file.

## 4. Verification

### Verify the installation

> $ grype version

#### Expected output:

> Application: grype  
> Version: `<version>`
